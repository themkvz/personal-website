A running list of references that keep coming back up during implementation
work, kept here instead of scattered across browser bookmarks.

## Browser & performance

- MDN's documentation on the Performance panel and layout thrashing.
- The Chrome DevTools Protocol docs, for anything that needs scripted
  profiling.

## Accessibility

- The WAI-ARIA Authoring Practices Guide, for the correct pattern before
  inventing one.
- WebAIM's contrast checker, used more than any other single tool in this
  list.

## Architecture

- Martin Fowler's writing on the strangler-fig pattern, referenced directly
  in the frontend modernization notes on this Workbench.
