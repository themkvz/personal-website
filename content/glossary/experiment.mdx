---
term: Experiment
summary: A controlled comparison between variants of a feature, run on real traffic, to measure which one performs better against a defined metric.
related:
  - feature-flag
---

An experiment assigns visitors to a control and one or more treatment variants, usually through the same mechanism as a feature flag, and compares an outcome metric between groups once enough traffic has accumulated to distinguish a real effect from noise.

The assignment has to happen before the variant is rendered, and it has to be recorded against the same visitor identity as every action that follows, or the result measures nothing meaningful. Server-side assignment (resolved before the document is sent) avoids the flicker of a page rendering the default and then swapping to the assigned variant once JavaScript wakes up, which itself would bias the very metrics the experiment is trying to measure cleanly.
