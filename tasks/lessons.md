# Lessons

## Copy voice (2026-09-06)

**Correction:** first-person lane descriptions ("What I'm making") were
rejected — the contraction in particular.

**Rule:** chrome and UI copy is impersonal noun phrases ("Work in progress").
First person is fine in long-form content, where it should state ownership and
cost, not list tasks. Draft the noun-phrase version first.

## Content bodies are not Prose (2026-09-06)

**Observation:** experience entry bodies render in a bare `<div>`, so markdown
lists lose their markers. Only workbench artifact bodies get the `Prose`
wrapper.

**Rule:** check which wrapper renders a content collection's body before
authoring lists or headings into it.
