---
term: Devtools
summary: A browser's built-in tools for inspecting, debugging, and profiling a running page.
---

Devtools are usually the fastest path to an answer that intuition gets wrong. The Elements panel shows the live DOM and computed styles, not just the source the browser started with. The Network panel shows what actually got requested, in what order, and how long each took. The Performance panel records a timeline of scripting, rendering, and painting, which is the source of truth for where a slow page's time is actually going.

The Console lets you run JavaScript commands directly against the page's own state, one line at a time. Reaching for a profiler before reaching for a fix is the habit devtools are built to support — assuming the bottleneck instead of measuring it is one of the most common ways a performance fix fails to help.
